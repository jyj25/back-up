# 스마트 분리수거 로봇 (AI2 8조)

팀장 이정민 · 정유정 · 서민형 (3명 진행)

로봇 위에 쓰레기를 올리면 **로봇에 달린 카메라와 보드 안의 AI(엣지 AI)** 가 종류를 알아보고,
로봇이 **그 종류의 통까지 스스로 찾아간 뒤** 출발점으로 돌아온다.
분리수거 현황은 웹 대시보드와 휴대폰에서 본다.

> 📄 **프로젝트 문서**: [`docs/project/`](docs/project/README.md) — 범위·역할·요구·설계·작업·위험·시험·인계 (최신)
>
> 발표: **11월 3일(화) 14:00 무렵** · 배포된 웹 슬라이드 · 15분 (왜? / 어떻게? / 역할 분담 / 시연 영상 / 라이브 시연 / 한계)

## 왜?

- 분리수거를 헷갈리거나 귀찮아서 대충 버리면 재활용률이 떨어진다.
- 사람 대신 카메라와 AI가 종류를 판단하고, 로봇이 알맞은 통까지 옮겨 주면 실수가 줄어든다.
- 클라우드가 아니라 **보드 안에서** 판단해서(엣지 AI) 인터넷이 없어도 빠르게 동작한다.

## 어떻게? (구성)

```
                     ┌──────────────── 라즈봇 V2 (메카넘 바퀴) ────────────────┐
 쓰레기 올리기 ─▶ 트레이 ◀─ XIAO ESP32S3 카메라: AI 분류 ── USB ──▶ 라즈베리파이 5 ── 조종 서버(FastAPI)
                     │                                                     │   ├ 라즈봇 기본 카메라: 통의 마커 찾기
                     │                                                     │   └ 초음파: 거리, 장애물 정지
                     └─────────────────────────────────────────────────────┘
                                         │ Wi-Fi (휴대폰 핫스팟)
               웹: 실시간 상태 · 통별 개수 · 탄소 절감량        앱(휴대폰 웹앱): 조종 · 알림 · 포인트
```

1. 출발점에서 쓰레기를 트레이에 올린다.
2. ESP32 카메라가 종류(캔 `can` / 페트 `pet` / 종이 `paper`, 빈 트레이 `empty`)를 판정해 라즈베리파이에 USB 로 보낸다.
3. 로봇이 그 통에 붙은 **ArUco 마커**(번호표)를 카메라로 찾아가 통 앞에 멈춘다. 통에 넣는 방법은 검토 중 (그전까지는 도착 신호 후 사람이 넣는다).
4. 출발점 마커로 돌아온다. 웹에 기록이 쌓인다.

| 장비 | 쓰임 |
| --- | --- |
| 라즈베리파이 5 + Yahboom 라즈봇 V2 | 이동(앞뒤·회전·옆·대각선), 조종 서버, 초음파, 카메라 받침 |
| 라즈봇 기본 USB 카메라 | 앞을 보며 통의 마커 찾기 |
| XIAO ESP32S3 Sense (팀원 것) | 트레이 위 쓰레기 분류 (Edge Impulse), USB 로 결과 전송 |
| 아두이노 고급키트 (UNO) | 활용 검토 중 |
| 카메라 모듈 3 · C270 웹캠 | 예비 |
