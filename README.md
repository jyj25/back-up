# 스마트 분리수거 로봇 (AI2 8조)

이정민 서민형 정유정 이태겸

카메라가 쓰레기 종류(캔 / 페트 / 종이)를 **보드 안의 AI(엣지 AI)** 로 알아보고, 서보모터가 트레이를 기울여 맞는 통에 넣는다.
분리수거 현황은 웹 대시보드와 휴대폰에서 실시간으로 본다.

> 발표: **11월 3일(화) 14:00 무렵** · 배포된 웹 슬라이드 · 15분 (왜? / 어떻게? / 역할 분담 / 시연 영상 / 라이브 시연 / 한계)

---

## 왜?

- 분리수거를 헷갈리거나 귀찮아서 대충 버리면 재활용률이 떨어진다.
- 사람 대신 카메라와 AI가 종류를 판단하고, 기계가 알아서 나눠 담으면 실수가 줄어든다.
- 클라우드가 아니라 **보드 안에서** 판단해서(엣지 AI) 인터넷이 없어도 빠르게 동작한다.

## 어떻게? (구성)

```
노트북 웹캠 ─▶ 대시보드 ─ 사진(96×96) ─▶ XIAO ESP32S3 ─ AI 판정 ─▶ 서보: 트레이 기울이기 ─▶ 캔 / 페트 / 종이 통
                    │                          │
                    │                          └─▶ 아두이노 UNO: 통별 개수(FND), 상태 색(RGB LED), IR 리모컨 수동 조작
                    ▼
            웹: 실시간 판정 · 통별 개수 · 탄소 절감량       앱(휴대폰 웹앱): 통이 차면 알림 · 분리수거 포인트
```

| 장비 | 쓰임 |
| --- | --- |
| XIAO ESP32S3 | Edge Impulse 분류 모델 실행, 서보 제어, Wi-Fi |
| 아두이노 고급키트 (UNO) | 서보(K18), FND(K21/K22), RGB LED(K11), IR 리모컨(K16) |
| 노트북 웹캠 | 트레이 촬영 (XIAO Sense 카메라는 고장이라 사용 안 함) |
| 라즈봇 (선택) | 통이 차면 수거차처럼 이동 |

## 역할 분담 (확정 전)

| 역할 | 담당 | 하는 일 |
| --- | --- | --- |
| **AI** | (미정) | 사진 수집, Edge Impulse 학습, ESP32 추론 |
| **로봇** | (미정) | 기울어지는 트레이·통 제작, 서보 제어, 아두이노 패널 |
| **웹** | (미정) | 실시간 대시보드, 통계, 발표 웹 슬라이드 배포 |
| **앱** | (미정) | 휴대폰 웹앱(알림·포인트), 시연 영상 촬영·편집 |

3명이면 **웹 + 앱**을 한 사람이 맡는다 (휴대폰 웹앱은 대시보드를 휴대폰 화면에 맞춘 것).

## 예상 할 일

### AI
- [ ] 분류할 물건 확정 (예: `can`, `pet`, `paper`, 빈 트레이 `empty`)
- [ ] 클래스마다 50장 이상 촬영 (사진 수집기 사용)
  - [ ] **모든 클래스에 손이 나온 사진을 비슷하게** 넣기 (손·얼굴을 보고 판단하는 '지름길 학습' 방지)
  - [ ] 각도 · 거리 · 찌그러짐 · 조명 바꿔 가며
- [ ] Edge Impulse 학습 → ESP32S3 용 라이브러리 설치 (`train_ei.py`)
- [ ] 보드에서 정확도·속도 측정 (목표: 90% 이상, 1초 이내)
- [ ] 틀린 장면을 모아 다시 학습 (최소 1회)
- [ ] 발표 장소 조명에서 사진 추가 촬영 → 재학습

### 로봇 (하드웨어)
- [ ] 트레이 · 통 3개 제작 (종이상자 / 우드락)
- [ ] 서보 하나로 트레이를 **왼쪽 · 가운데 · 오른쪽**으로 기울이는 구조
- [ ] 서보 연결 방식 결정: XIAO 에 바로 vs UNO 를 거쳐서
- [ ] 서보 각도 보정 (통마다 떨어지는 각도, 원위치)
- [ ] UNO 패널: 통별 개수 FND 표시, 판정 색 RGB LED, IR 리모컨으로 수동 분류
- [ ] 무거운 물건 테스트 (키트 서보 힘이 약하면 빈 용기 · 작은 크기로)
- [ ] (선택) 라즈봇: 통이 차면 이동

### 펌웨어 (AI + 로봇 공동)
- [ ] 기존 추론 펌웨어에 서보 제어 추가
- [ ] **판정 확정 로직**: 같은 결과가 여러 번 연속 + 확신도 기준 이상일 때만 움직이기 (손 움직이는 중 오작동 방지)
- [ ] 분류 후 원위치 · 다음 물건 대기
- [ ] ESP32 ↔ UNO 통신 (시리얼 또는 Wi-Fi)

### 웹
- [ ] 실시간 대시보드: 카메라 화면, 모델이 보는 화면, 판정 결과, 확신도
- [ ] 통별 누적 개수, 오늘 처리량, **탄소 절감량** 계산
- [ ] 기록 저장 (서버 DB 또는 Supabase)
- [ ] 발표 웹 슬라이드 작성 → Vercel 배포

### 앱 (휴대폰 웹앱)
- [ ] 통 상태 · 개수를 휴대폰에서 보기 (반응형 화면, 홈 화면에 추가)
- [ ] 통이 차면 알림
- [ ] 분리수거 포인트 · 랭킹 (선택)

### 발표 준비
- [ ] 시연 영상 녹화 (라이브 시연 실패 대비)
- [ ] 슬라이드: 왜 → 어떻게(구성도) → 역할 분담 → 시연 영상 → 라이브 시연 → 한계·개선점
- [ ] 한계 정리: 지름길 학습, 조명 영향, 서보 힘, 추론 속도, 고장 난 부품(XIAO 카메라·부저·LCD)으로 바꾼 부분
- [ ] 리허설 (15분 시간 재기)
