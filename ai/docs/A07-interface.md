# 인터페이스·데이터 계약 (AI ↔ 수집기·웹·로봇)

문서 ID: A07 / 버전: 0.1 (2026-10-30)
출처 양식: kdigital-physical-ai project-practice A07

## IF-01 보드 → PC 영상 (구현됨, 수집용)
| 항목 | 내용 |
| --- | --- |
| 물리 | USB 시리얼 (XIAO ESP32S3, 현재 COM4), 115200 (USB CDC라 속도는 의미 없음) |
| 요청 | PC가 ASCII `C` 1바이트 전송 |
| 응답 | `AA 55 AA 55` + 길이(uint32 little-endian) + JPEG 바이트. 요청 1회당 프레임 1장 |
| 영상 | JPEG, VGA 640×480, 품질 12. 센서 OV3660 |
| 보조 | Wi-Fi AP `XIAO_ESP32S3_Sense` → `http://192.168.4.1/` (대시보드), `:81/stream` (MJPEG), `:81/capture` (JPEG 1장) |
| 응답 없음 | PC는 2초 안에 프레임이 없으면 "응답 없음"으로 처리 (수집기 구현) |
| 부팅 로그 | 같은 포트에 텍스트 로그가 섞일 수 있어 매직 바이트로 동기화 |

## IF-02 모델 판정 출력 (미확정 — 팀 합의 필요)
| 항목 | 제안(가정) |
| --- | --- |
| 형식 | LF로 끝나는 JSON 한 줄: `{"class":"can","conf":0.93,"ms":173}` |
| 판정 없음 | `{"class":null,"conf":0.41,"ms":173}` |
| 입력 | 96×96 이미지를 어떤 경로(보드 카메라 / 웹캠→PC→보드)로 받을지 **미확정** |
| 변경 원본 | 이 파일(`ai/docs/A07-interface.md`). 바꾸면 로봇·웹 담당에게 알린다 |
