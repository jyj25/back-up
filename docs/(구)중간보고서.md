## 1. 주제와 목표

**로봇 위에 쓰레기를 올리면, 로봇에 달린 카메라의 AI가 종류를 판단하고 로봇이 해당 분리수거 통까지 스스로 찾아간 뒤 출발점으로 돌아온다.**

- 왜: 분리수거를 헷갈리거나 귀찮아서 대충 버리면 재활용률이 떨어진다. 판단(AI)과 운반(로봇)을 자동화해 실수를 줄인다.
- 수업 장비 활용: 라즈봇 키트(이동·조종), ESP32S3(엣지 AI 분류). 아두이노 키트 활용은 검토 중.
- 역할: 수업 조건의 AI · 로봇 · 웹사이트 · 앱 네 영역을 3명이 나눠 맡는다.

## 3. 아이디어 선정과 변경

**후보**: 여러 입력으로 함께 조종하는 로봇 게임, 공부 중 폰 사용 감지 도우미, 교실 배달 로봇, 반도체 공정 관련 아이디어(웨이퍼 운반 AGV, 불량 분류 컨베이어 등), 스마트 분리수거 등.
로봇 담당 아이디어 5개는 [`jeongmin/docs/kj-ideas.md`](../jeongmin/docs/kj-ideas.md).

**선정 이유 — 스마트 분리수거**
- 팀원 다수가 선호했고, 일상 문제라 "왜?" 를 설명하기 쉽다.
- 수업에서 해 본 **Edge Impulse 이미지 분류(ESP32S3)** 를 그대로 활용할 수 있다.
- AI(분류) → 로봇(운반) → 웹·앱(기록·알림)으로 역할이 자연스럽게 이어진다.

**변경 (10/30)**

| | 처음 계획 (v1) | 바뀐 계획 (v2) |
| --- | --- | --- |
| 분류 카메라 | 노트북 웹캠 | **로봇 위 ESP32S3 카메라** (USB 로 라즈베리파이에 결과 전달) |
| 옮기는 방법 | 고정된 트레이를 기울여 통에 넣음 | **로봇이 통까지 이동** (통에 넣는 방법은 검토 중) |
| 라즈봇 | 선택 사항 | **핵심** (이동 · 통 찾기 · 장애물 정지) |

바꾼 이유: 라즈봇 키트를 실제로 쓰는 역할이 생기고, 로봇 담당이 맡을 일이 분명해지며, 시연에서 보여 줄 장면이 생긴다.

## 4. 시스템 구성

```
 쓰레기 ─▶ 트레이 ◀── XIAO ESP32S3 카메라 (AI 분류) ── USB ──▶ 라즈베리파이 5 (조종 서버)
                                                                 ├ 라즈봇 기본 카메라: 통의 마커 찾기
                                                                 ├ 초음파: 거리, 장애물 정지
                                                                 └ 메카넘 바퀴 4개: 이동
                                       │ Wi-Fi (휴대폰 핫스팟)
                 웹: 상태 · 통별 개수 · 탄소 절감량      앱(휴대폰 웹앱): 조종 · 알림
```

통마다 **ArUco 마커**(번호표: 출발점 0, 재활용 1, 일반쓰레기 2, 비닐 3)를 붙이고, 로봇은 "조금 움직이고 → 멈춰서 보고 → 다시 판단" 을 반복해 해당 마커 앞 약 25cm 까지 간다.
