## 공통 규칙 (제안)
- 한 줄 = 한 메시지, UTF-8, LF 로 끝남. 받는 쪽은 파싱 실패한 줄을 버리고 다음 줄을 기다린다.
- 값 없음은 `null`, 오류는 `error` 필드. 0 으로 채우지 않는다.
- 필드를 바꾸면 이 문서를 먼저 고치고 영향받는 담당(로봇·웹)에게 알린다. 변경 원본 = 이 파일.
