## 공통 규칙 (제안)
- 한 줄 = 한 메시지, UTF-8, LF 로 끝남. 받는 쪽은 파싱 실패한 줄을 버리고 다음 줄을 기다린다.
- 값 없음은 `null`, 오류는 `error` 필드. 0 으로 채우지 않는다.
- 필드를 바꾸면 이 문서를 먼저 고치고 영향받는 담당(로봇·웹)에게 알린다. 변경 원본 = 이 파일.

## 라즈봇과 USB 로 연결할 때 (2026-10-30 전달받음)
- 라즈봇이 USB 호스트가 되고, ESP32 의 판정 JSON(IF-02)을 시리얼로 읽는다. 라즈봇 쪽 포트 이름은 보통 `/dev/ttyACM0` 형태이고 읽기 권한(`dialout` 그룹)이 필요할 수 있음 (가정, 라즈봇 담당 확인).
- **같은 USB 포트를 쓰므로 노트북의 사진 수집기(Web Serial)와 동시에 쓸 수 없다.** 사진 수집은 라즈봇을 뽑고 노트북에 직접 연결해서 한다.
- **디버그 로그와 판정 JSON 이 같은 포트에 섞인다.** 받는 쪽은 `{` 로 시작하지 않는 줄을 버린다. 보드 재시작 시 부팅 로그도 나오므로 반드시 필요한 규칙이다.
- 라즈봇(라즈베리파이 기반이라면 Wi-Fi 사용 가능)이 서버로 결과를 대신 보낼 수 있다. 그러면 보드가 Wi-Fi 에 붙을 필요가 없다 — ADR-02 참고 (가정).
- 보드 전원을 라즈봇 USB 에서 받으면 서보 전류는 그 전원에서 빼서 쓰면 안 된다 (A20).
