# 접근·비밀·데이터 위험 메모

문서 ID: A21 / 버전: 0.1 초안 (2026-10-30)

| 항목 | 내용 |
| --- | --- |
| 데이터 흐름 | 카메라 사진 → (수집 시) 각자 PC 브라우저 → ZIP → Edge Impulse(학습). 시연 시 사진은 보드에서 판정 후 폐기, 서버에는 판정 기록만 저장하는 것을 권장(가정) |
| 개인정보 | 사진에 손·얼굴이 찍힐 수 있음. 원본 사진은 공개 저장소에 올리지 않고, 학습 후 팀 밖에 공유하지 않는다 |
| 비밀값 | `EI_API_KEY`(`.env`), Wi-Fi 이름·비밀번호(`secrets.h`). `.gitignore` 로 제외했고 커밋하지 않는다. 노출되면 키를 재발급한다 |
| 공유기 정보 | 팀 채팅·문서에 비밀번호를 적지 않는다 |
| 보드 AP | 비밀번호 `seeedstudio` 는 제조사 기본값이라 보안 수단이 아님. 시연 때 외부에서 접속할 수 있다는 점을 알고 쓴다 |
| 수집기 저장 | 사진은 접속한 PC 의 브라우저에만 저장됨. 공용 PC 에서는 ZIP 을 받은 뒤 삭제 |
| 확인 안 된 것 | 서버/DB(Supabase) 접근 권한, 웹 대시보드 공개 범위 — 웹 담당이 정한 뒤 추가 |
| 표준과의 관계 | 이 메모는 수업 프로젝트용 점검 목록이며 인증이나 제품 검사를 대신하지 않는다 |
