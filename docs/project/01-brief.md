# 01 · 착수 개요·범위 (A01)

## 사용자와 상황

- **사용자**: 교실·사무실처럼 쓰레기를 한곳에 모았다가 나눠 버리는 사람. 분리수거 기준을 헷갈리거나 귀찮아하는 사람.
- **이번 시연의 실제 사용자**: 발표장의 강사·수강생. 로봇에 물건을 올리고 결과를 지켜본다.
- **상황**: 출발점에 로봇이 있고, 몇 걸음 떨어진 곳에 분류 종류별 통 3개가 놓여 있다.

## 문제와 근거

| 구분 | 내용 |
| --- | --- |
| 가정 | 분리수거 기준이 헷갈리거나 귀찮으면 대충 버리게 되고 재활용률이 떨어진다 |
| 미확인 | 실제 사용자 관찰·설문은 하지 않았다. 재활용 관련 수치는 발표 전 출처 있는 자료로 보완 |
| 사실 | 수업에서 Edge Impulse 이미지 분류를 ESP32S3 에서 실행해 본 경험이 있다 |
| 사실 (담당자 기록) | 팀원 XIAO ESP32S3 Sense 보드의 카메라(OV3660)는 초기화·영상 전송이 된다 (10/28, AI 시험 TC-16) |

## 목표

로봇 위 트레이에 물건을 올리면 **로봇에 달린 ESP32S3 카메라의 AI 가 종류를 판정하고, 로봇이 해당 통까지 스스로 찾아간 뒤 출발점으로 돌아온다.** 처리 기록을 웹에서 본다.

## 범위

**이번 버전에 포함**
- 분류 3종 + 빈 트레이. 종류 이름은 **미결정** — AI 안 `can / pet / paper / empty`, 로봇 안 `recycle / general / vinyl` ([04](04-design.md) ADR-05)
- 로봇 위 ESP32S3 카메라로 분류, 판정 JSON 을 USB 로 라즈베리파이에 전달 (IF-01)
- 통에 붙인 마커(ArUco)를 보고 찾아가기, 출발점 복귀
- 안전장치: 자동 정지, 속도 상한, 앞 장애물 정지, 수동 조작 시 즉시 취소
- 휴대폰 조종 화면(수동 분류 겸용), 웹 대시보드(상태·통별 개수)
- 발표장 Wi-Fi(휴대폰 핫스팟) 연결
- AI 도구: 사진 수집기, 보드 영상 펌웨어, 학습 스크립트, 추론 펌웨어 (세부는 AI 원본 A03)

**제외**
- 실제 쓰레기 처리량·무거운 물건, 여러 로봇, 원격(인터넷) 관제
- 지도 만들기(SLAM), 사람 피해 다니기
- 통이 찼는지 감지 센서 (개수 기준 알림은 선택 기능 REQ-08)
- **통에 넣는 방법은 미정** — 정해지기 전에는 "도착 신호 후 사람이 넣기" 로 시연 (ADR-04)
- 아두이노 UNO 패널(개수 표시·IR 리모컨) — 활용 검토 중, 이번 범위에서는 제외

## 제약 (자세히는 [05](05-tasks-risks.md))

- 사람: 3명 진행. 대면 통합은 **11/1(일) 오후 한 번**.
- 장비: 라즈베리파이 5 + 라즈봇 V2(조립 중), ESP32S3 카메라 보드는 팀원 것 1개.
- 데이터: 분리수거 사진은 아직 없음 (10/30 기준, 담당자 기록).
- 시간: 발표까지 4일. 실제 로봇 주행 조정과 모델 학습이 같은 기간에 겹친다.
- 환경: 발표장 Wi-Fi·조명·바닥이 연습 환경과 다를 수 있다.
