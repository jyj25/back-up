## RACI (R 수행 · A 최종 판단 · C 의견 · I 공유)

| 일 | 이정민 | 정유정 | 서민형 |
| --- | --- | --- | --- |
| 범위·일정 결정 (01, 05) | **A** R | C | C |
| 분류 종류·라벨 이름 (ADR-05) | C (통 이름) | **A** R | I |
| IF-01 판정 JSON 형식 | C (받는 쪽) | **A** R (보내는 쪽) | C (기록에 사용) |
| 판정 확정 규칙 (REQ-01) | C | **A** R | I |
| 로봇 이동·안전 (REQ-02, 03) | **A** R | I | I |
| 통에 넣는 방법 (ADR-04) | **A** R | C | C |
| IF-02 로봇 API 변경 | **A** R | C | C (쓰는 쪽) |
| 대시보드·웹앱 (REQ-06) | C | I | **A** R |
| 발표 슬라이드 내용 | C (로봇 파트) | C (AI 파트) | **A** R (배포) |
| 시험 실행·기록 (06) | R (로봇) | R (AI) | R (웹) |
| PR 검토·합치기 | **A** R | I | I |

- **독립 검토는 아직 없다.** 로봇·AI 문서 모두 "검토자: 아직 없음". 11/1 모임에서 서로의 파트를 한 번씩 검토한다.

## 운영 규칙

- **작업**: 자기 이름 브랜치·폴더 → Pull Request → 팀장이 검토 후 합친다 (강사 규칙). 팀 공용 문서(`README.md`, `docs/`)도 PR 로.
- **인터페이스 변경 원본**: IF-01 판정 JSON 은 AI 원본 문서(`yujeong/docs/A07-interface.md`)가 원본, 로봇 API(IF-02)는 `jeongmin/README.md` 가 원본. 바꾸면 이 문서와 상대 담당에게 먼저 알린다.
- **결정 기록**: 중요한 선택은 [04](04-design.md) ADR 에, 바뀐 것은 [05](05-tasks-risks.md) 변경 기록에.
- **소통**: 카톡방(제안), 하루 한 줄 "오늘 한 일 / 막힌 것" 공유. 이견이 남으면 미해결로 적고 팀장이 기한을 정해 결정.
- **기한**: 각자 **10/31(토) 밤까지 PR**, 11/1(일) 오후 대면 통합.
