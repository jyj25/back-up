# 09 · 데이터·AI 평가 카드 (A19, 부록)

원본: `yujeong/ai/docs/A19-data-ai.md` (정유정). 아래는 팀 구조에 맞춰 요약·보완한 것.

| 항목 | 내용 |
| --- | --- |
| 적용 | 트레이 위 물건 이미지 분류 3종 + 빈 트레이. 종류: `can`, `pet`, `paper`, `empty` (ADR-05 결정, 통 이름과 같음). 보드(ESP32S3) 안에서 추론 |
| 데이터 출처 | 팀원이 직접 촬영 (수집기). 외부 데이터 없음 |
| 촬영 조건 | **로봇 위 카메라 받침과 같은 방향·거리**, 트레이 바닥 진한 색. 카메라가 90° 누워 있으므로 수집·추론 방향을 같게 |
| 라벨 | 파일명 접두어(`클래스.시간-번호.jpg`)로 Edge Impulse 업로드 시 자동 지정 |
| 표본 | **현재 0장** (10/30, 담당자 기록). 목표 클래스당 50장 이상, 손 포함 비율 비슷하게 |
| 모델 | Edge Impulse 이미지 분류(전이학습), 입력 96×96. 새 프로젝트 사용 여부 미정 (기존 프로젝트에는 다른 물건 72장만 있음) |
| 장치 | XIAO ESP32S3 Sense (OV3660), esp32 core 3.3.12 |
| 평가 | train/test 80/20, 테스트 셋은 학습에 쓰지 않음. 혼동 행렬, 보드 실측 정확도·추론 시간 (TC-08, TC-18) |
| 누수 주의 | 연속 촬영한 거의 같은 사진이 train/test 에 나뉘면 정확도가 부풀려짐 → 촬영 세션 단위로 나누는 것을 검토 |
| 확정 규칙 | 확신도 ≥ 0.80, 1·2등 차이 ≥ 0.20, 3번 연속 (가정 — 실제 확신도 분포를 본 뒤 조정) |
| 개인정보 | 손·얼굴이 찍힐 수 있음. 학습용으로만, 원본 사진은 공개 저장소에 올리지 않음 |
| 현재 결과 | 없음 (학습 전) |

## 사실 / 가정 / 미확인

- 사실 (담당자 기록): 기존 보드 펌웨어의 96×96 추론은 약 173 ms. 재활용 데이터는 아직 없음.
- 가정: 시연 환경도 수집 때와 비슷한 조명·카메라 방향.
- 미확인: 정확도, 새 모델의 추론 시간, 실제 확신도 분포. 검토자: 아직 없음.
