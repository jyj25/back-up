# 10 · 부품·연결·전원 (A20, 부록)

원본: 로봇 `jeongmin/docs/robot-specs.md`, AI `yujeong/docs/A20-bom-wiring.md`. 실물 배선 확인은 대부분 **미확인** (조립 중).

## 연결

```
라즈봇 배터리 → 라즈봇 기판 → 라즈베리파이 5
                              ├ I2C 0x2B : 라즈봇 기판 (모터·센서·서보·LED)
                              ├ USB (파란 단자) : 라즈봇 기본 카메라
                              └ USB (검은 단자) : XIAO ESP32S3 (전원 + 판정 JSON, IF-01)
```

## 전원

- 라즈베리파이 5 는 전원 방식에 따라 **USB 단자 전체가 0.6A 로 제한**될 수 있다 → 장치를 다 꽂고 **주행 중** `vcgencmd get_throttled` 가 `0x0` 인지 확인 (RISK-05).
- XIAO ESP32S3 + 카메라: 평균 약 140mA, 캡처 순간 약 347mA (AI 원본 A20, 제조사 자료 기준).
- 순간 전류가 큰 장치(모터류)를 추가하면 USB 가 아니라 라즈봇 기판 쪽 전원에서 따로 받는다 — 통에 넣는 장치가 정해지면 여기서 다시 검토 (ADR-04).
- 서버 쪽 확인: 라즈베리파이에서 보드는 보통 `/dev/ttyACM0`, 읽기 권한(`dialout` 그룹) 확인.

## 실물 확인 (조립 후 채움)

- 전원 상태(주행 중 throttled 값), USB 장치 인식, 카메라 받침 위치 사진: 미확인
