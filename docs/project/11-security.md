# 11 · 접근·비밀·데이터 위험 메모 (A21, 부록)

원본: AI `yujeong/docs/A21-security-privacy.md` + 로봇 쪽 내용. 수업 프로젝트용 점검 목록이며 인증·제품 검사를 대신하지 않는다.

| 항목 | 내용 |
| --- | --- |
| 저장소 | **공개 저장소**. Wi-Fi 이름·비밀번호, 라즈베리파이 IP·계정·비밀번호, API 키(`EI_API_KEY`)를 커밋하지 않는다. `.env`, `secrets.h`, `robot.env` 는 `.gitignore` 로 제외 |
| 노출 시 | 키는 재발급, 비밀번호는 변경. 팀 채팅·문서에도 비밀번호를 적지 않는다 |
| 사진 데이터 | 손·얼굴이 찍힐 수 있음. 원본 사진은 공개 저장소에 올리지 않고 학습 후 팀 밖에 공유하지 않는다. 수집 사진은 브라우저에만 저장되므로 공용 PC 에서는 ZIP 을 받은 뒤 삭제 |
| 시연 중 사진 | 보드에서 판정 후 저장하지 않음. 로봇은 판정 기록(종류·확신도·시각)만 남긴다 (제안) |
| 로봇 조종 접근 | 같은 핫스팟에 붙은 사람은 누구나 조종 화면에 접속할 수 있다 → 시연 중 핫스팟 비밀번호를 공유하지 않는다. 브라우저 API 호출은 `CORS_ORIGINS` 에 적은 웹 주소만 허용 |
| 보드 Wi-Fi AP | 수집용 보드 AP 의 비밀번호는 제조사 기본값이라 보안 수단이 아님. 시연 때는 보드 Wi-Fi 를 쓰지 않는다 (USB 연결) |
| 원격 접속 | 라즈베리파이 SSH 는 키 로그인, `sudo` 는 사람이 비밀번호 입력 |
| 미확인 | 대시보드 공개 범위·저장소(서민형이 정한 뒤 추가) |
