## 읽는 규칙

- **사실 / 가정 / 미확인**을 구별해 적는다. 팀원이 아직 알려 주지 않은 진행 상황은 `미확인` 으로 둔다.
- 시험 상태: `PASS`(실제 실행해서 기대와 일치) · `FAIL` · `BLOCKED`(선행 조건 없음) · `NOT_RUN`(실행 전).
  노트북 가짜 모드 시험의 PASS 를 **실제 로봇 동작의 PASS 로 읽지 않는다.**
- `제안` 은 팀 합의 전, `결정` 은 팀장이 정했거나 팀이 합의한 것.
- 기준: 2026-10-30, 커밋 `a14f0ce`. 문서를 고치면 같은 PR 에서 관련 ID 문서도 함께 고친다.
- 공개 저장소: Wi-Fi 비밀번호, 기기 IP·계정, API 키는 적지 않는다.
