# KJ법 아이디어 5개 (이정민, 로봇 담당)

선생님 규칙: 서로 상의하지 않고 인당 5개 → 공개 → 비슷한 것끼리 묶기(클러스터, 태그) → 2개 이하가 될 때까지 다시 묶기 → 토론 → 최종 피칭 (FigJam).
로봇(라즈봇)이 **꼭 필요한** 아이디어 위주로 골랐다. FigJam 포스트잇에는 굵은 한 줄만 쓴다.

| # | 포스트잇 한 줄 | 내용 | 로봇이 하는 일 | 다른 역할 |
| --- | --- | --- | --- | --- |
| 1 | **바닥 쓰레기를 찾아 분리수거하는 로봇** | 라즈봇 카메라가 바닥의 캔·페트·종이를 알아보고 밀어서 구역별로 모은다 | 카메라로 찾기 → 다가가기 → 정해진 구역으로 밀기 | AI: 쓰레기 분류 / 웹: 수거 통계 / 앱: 알림 |
| 2 | **반도체 팹 웨이퍼 운반 AGV 축소판** | 바닥 선을 따라 공정 장비(스테이션) 사이를 오가며 웨이퍼 상자를 나른다. 아두이노 RFID(K25)로 도착 확인 | 라인 따라가기, 초음파로 충돌 방지, 스테이션에서 정지 | AI: 장애물 인식 / 웹: 운반 현황판 / 앱: 호출 |
| 3 | **여러 방법으로 함께 조종하는 로봇 게임** | 조이스틱(UNO)·표정(웹캠)·소리·휴대폰 기울기로 한 로봇을 나눠 조종해 코스를 완주 | 받은 명령대로 이동, 옆·대각선 이동이 게임 재미 | AI: 표정·소리 인식 / 웹: 점수판 / 앱: 휴대폰 컨트롤러 |
| 4 | **공부 중 폰 보면 다가오는 집중 도우미** | 책상 카메라가 스마트폰 사용을 감지하면 로봇이 그 자리로 가서 부저·LED 로 경고 | 지정 자리로 이동, 경고, 집에 복귀 | AI: 폰 감지 (이미 학습해 본 모델) / 웹: 집중 시간 통계 / 앱: 랭킹 |
| 5 | **교실 물건 배달 로봇** | 자리 번호를 고르면 로봇이 선을 따라가 물건(필기구 등)을 배달하고 돌아온다 | 라인 따라가기, 갈림길 선택, 도착 알림 | AI: 사람·손 인식으로 수령 확인 / 웹: 호출 화면 / 앱: 주문 |

## 클러스터링할 때 참고 (내 생각)

- **이동·운반** (2, 5) / **인식 후 행동** (1, 4) / **조종·놀이** (3) 로 나뉜다.
- 팀 후보였던 "스마트 분리수거(트레이 기울이기)" 는 1번과 같은 묶음 → 로봇이 **직접 돌아다니며 모으는** 버전으로 확장 가능.
- 6일 안에 완성하기 쉬운 순서: 3 > 4 > 5 > 2 > 1 (1번은 '밀어서 옮기기' 가 어렵다)
