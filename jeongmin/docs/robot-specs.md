# 로봇 성능 메모 (Raspbot V2 + Raspberry Pi 5)

프로젝트에서 로봇에게 무엇을 맡길지 정할 때 보는 표. **"확인"** 은 문서·라이브러리 코드로 확인한 값, **"측정 필요"** 는 조립 후 직접 재야 하는 값이다.

## 구성

| 부품 | 내용 | 근거 |
| --- | --- | --- |
| 컴퓨터 | Raspberry Pi 5, RAM 8GB | 실물 (`/proc/device-tree/model`) |
| OS | Raspberry Pi OS (Debian 13 trixie), Python 3.13 | 실물 |
| 차체 | Yahboom Raspbot V2, **메카넘 바퀴 4개** (앞뒤·회전 + **옆·대각선 이동**) | 확인 |
| 제어 기판 | 차체 기판의 마이크로컨트롤러, 라즈베리파이와 **I2C 버스 1, 주소 0x2B** | 확인 (raspbot 라이브러리) |
| 모터 | 4개 (왼앞 L1, 왼뒤 L2, 오앞 R1, 오뒤 R2), 속도 값 0~255 | 확인 (라이브러리) |
| 서보 | 카메라 받침 2개: 좌우(pan) 0~180°, 위아래(tilt) **0~110°** (기구 한계) | 확인 (라이브러리) |
| 거리 센서 | 초음파 (HC-SR04 호환), mm/cm 로 읽음 | 확인 |
| 바닥 센서 | 적외선 라인 센서 4채널 (왼쪽→오른쪽 x1~x4) | 확인 |
| 기타 | RGB LED 바 14개(WS2812), 부저, 버튼(KEY1), IR 리모컨 수신기, OLED 연결 가능(0x3C) | 확인 |
| 카메라 (길 찾기) | **라즈봇 기본 USB 카메라**, 서보 받침 위 → 앞을 보며 마커 찾기 (`CAMERA=usb`) | 실물 (조립 때 장착) |
| 카메라 (분류) | 팀원 XIAO ESP32S3 Sense, 로봇 위에서 트레이를 내려다봄. 라즈베리파이 USB 로 전원 + 결과 | 계획 |
| 예비 카메라 | Raspberry Pi Camera Module 3 (12MP, 자동 초점), Logitech C270 (USB 720p) | 실물 |
| 전원 | 라즈베리파이 5 는 5V 5A 권장. 차체 배터리로 모터 + 라즈베리파이 | 문서 |

## 측정값 (조립 후 채우기)

`robot/scripts/hw_test.py` 로 점검하고, 아래 방법으로 잰다.

| 항목 | 값 | 재는 법 |
| --- | --- | --- |
| 직진 속도 (speed=100) | 측정 필요 | 바닥에 1m 테이프 → 걸린 시간. `POST /api/move {"action":"forward","speed":100,"duration_ms":3000}` |
| 직진 속도 (speed=150, 서버 기본 최대) | 측정 필요 | 위와 같음 |
| 옆 이동 정확도 | 측정 필요 | 1m 옆으로 갔을 때 앞뒤로 밀린 거리 (바퀴 X자 배치 확인) |
| 제자리 회전 360° 시간 | 측정 필요 | `turn_left` 로 한 바퀴 |
| 실을 수 있는 무게 | 측정 필요 | 물병 등을 올리고 출발이 되는지 |
| 배터리 사용 시간 | 측정 필요 | 완충 → 조종 서버 켜고 주기적으로 움직이며 꺼질 때까지 |
| 초음파 측정 범위·오차 | 측정 필요 | 10 / 30 / 100 cm 에 벽 → `GET /api/distance` |
| 장애물 정지 후 밀린 거리 | 측정 필요 | speed 100·150 으로 벽을 향해 직진 → 멈춘 뒤 벽까지 거리. 너무 가까우면 `OBSTACLE_CM` 을 올린다 |
| 마커 인식 거리 (10cm 마커) | 측정 필요 | 마커를 50cm·1m·2m 에 두고 `GET /api/markers` 에 나오는지 |
| 움직이는 최소 펄스 | 측정 필요 | speed 60 회전을 60·100·150ms 로 → 실제로 도는지 (안 돌면 `stations.json` 의 `turn_speed` 를 올린다) |
| 찾아가기 성공률 | 측정 필요 | 통 3개 × 5번, 도착 위치가 통 앞 20~30cm 인지 |
| 카메라 지연 | 측정 필요 | 화면에 스톱워치 → 조종 화면과 비교 |
| Wi-Fi 조종 지연 | 측정 필요 | 버튼 → 바퀴 움직일 때까지 체감 |

## 지금 알고 있는 제약

- **마커는 세워서 붙인다**: 카메라가 바닥 가까이에서 정면을 보고 위아래 서보가 고장이라, 바닥에 눕힌 마커는 못 읽는다.

- **조종 서버 안전장치**: 이동 명령은 최대 3초 뒤 자동 정지, 속도는 기본 150/255 까지 (`MAX_SPEED`), 앞 15cm 안에 물체가 있으면 정지 (`OBSTACLE_CM`). 시연 전에 실제 속도·제동 거리를 보고 조정한다.
- 초음파 센서는 **앞에만** 있다 → 뒤·옆 이동에는 장애물 정지가 없다.
- **Wi-Fi**: 라즈베리파이가 아는 Wi-Fi 에서만 접속된다. 학교·발표장에서는 휴대폰 핫스팟을 미리 등록해야 한다.
- **sudo** 는 비밀번호가 필요하다 (설정 변경·재부팅은 사람이 직접).
- 카메라 모듈 3 은 라즈베리파이 5 전용 **좁은 22핀 케이블**로 연결해야 한다 (예비).
- USB 장치(기본 카메라 + ESP32 + 예비)를 꽂으면 USB 전력이 모자랄 수 있다. 라즈베리파이 5 는 전원 방식에 따라 USB 전체가 0.6A 로 제한된다 → 다 꽂고 모터를 돌리는 중에 `vcgencmd get_throttled` 가 `0x0` 인지 확인. **쏟기 서보는 USB 가 아니라 라즈봇 기판 5V 에서** 전원을 받는다.
- USB 카메라가 여러 개면 번호(`CAMERA_INDEX`)가 바뀔 수 있다 → `/api/camera.jpg` 로 앞을 보는 카메라인지 확인.
