# 발표 슬라이드 (11/3 발표, 15분)

`index.html` 하나로 된 웹 슬라이드. 설치·빌드 없음.

| 키 | 동작 |
| --- | --- |
| → / Space / Enter | 다음 장 |
| ← / Backspace | 이전 장 |
| N | 발표자 메모 (누가 말할지, 시간) |
| F | 전체 화면 |

휴대폰은 좌우로 밀기. 주소 끝 `#5` 처럼 쪽 번호로 바로 이동.

- **시연 영상**: `video/demo.mp4` 로 저장하면 12쪽에서 재생된다 (없으면 안내 문구).
- **사진**: `img/` — 로봇 카메라·AI 보드 카메라로 찍은 실제 화면.
- 숫자(AI 정확도 등)가 바뀌면 해당 쪽을 고치고 PR.
- 로컬 확인: `python -m http.server 8000` → http://localhost:8000
- 배포: 이 폴더에서 `vercel --prod` (Vercel 프로젝트에 연결돼 있음).
