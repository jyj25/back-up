# 데이터·AI 평가 카드

문서 ID: A19 / 버전: 0.1 (2026-10-30)
출처 양식: kdigital-physical-ai project-practice A19

| 항목 | 내용 |
| --- | --- |
| 적용 여부 | 쓰레기 종류 4클래스(`can`, `pet`, `paper`, `empty`) 이미지 분류. 보드(ESP32S3) 안에서 추론 |
| 데이터 출처 | 팀원이 직접 촬영 (수집기 `yujeong/ai/collector`). 외부 데이터 없음 |
| 라벨 | 파일명 접두어(`클래스.시간-번호.jpg`)로 EI 업로드 시 자동 지정 |
| 표본 | **현재 0장** (수집 전). 목표 클래스당 50장 이상, 손 포함 비율 비슷하게 |
| 개인정보 | 손·얼굴이 찍힐 수 있음. 학습용으로만 쓰고 공개 저장소에는 원본 사진을 올리지 않는다 |
| 모델 | Edge Impulse 이미지 분류 (Transfer learning). 기존 프로젝트 `jyj25-project-1`(id 1149702)의 Impulse: 입력 96×96, resize `squash` — 새 프로젝트 사용 여부 미정 |
| 장치 | XIAO ESP32S3 Sense, esp32 core 3.3.12 |
| 평가 계획 | train/test 80/20, 테스트 셋은 학습에 쓰지 않음. 혼동 행렬, 보드 실측 정확도·추론 시간 기록 |
| 누수 주의 | 연속 촬영한 거의 같은 사진이 train/test에 나뉘면 정확도가 부풀려짐 → 촬영 세션 단위로 나누는 것을 검토 |
| 현재 결과 | 없음 (학습 전) |

## 사실 / 가정 / 미확인
- 사실: EI 프로젝트 1149702에는 `airpod` 35장·`glassescase` 37장만 있고 재활용 데이터는 없음 (2026-10-28 API 조회). 보드에 올라가 있던 기존 펌웨어의 추론은 96×96 기준 약 173 ms (`airpod` 로그에서 확인).
- 가정: 시연 환경도 수집 때와 비슷한 조명·카메라 방향.
- 미확인: 정확도, 새 모델의 추론 시간, 새 EI 프로젝트 사용 여부. 검토자: 아직 없음.
