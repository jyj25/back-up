## 1. 목적과 범위
- 사용자: 분리수거를 헷갈리거나 귀찮아하는 사람. 장소: 시연 장소(교실) — 사실
- 목표: 카메라와 보드 안의 AI 가 캔 / 페트 / 종이를 판정하고, 서보가 트레이를 기울여 맞는 통에 넣는다. 현황은 웹과 휴대폰에서 본다 — 사실
- 제외: 실제 쓰레기 처리량, 무거운 물건(서보 힘 한계), 인터넷 없는 환경의 웹 기능 — 가정
- 발표: 11/3(화) 14:00 무렵, 15분, 배포된 웹 슬라이드(왜 / 어떻게 / 역할 분담 / 시연 영상 / 라이브 시연 / 한계) — 사실

## 3. 비기능 요구
- 보안: API 키(`.env`), Wi-Fi 정보(`secrets.h`)는 저장소에 올리지 않는다 (A21).
- 작업 방식: 각자 브랜치에 올리고 팀장이 검토·병합한다 — 선생님 공지.
- 시험은 실제로 실행한 것만 PASS 로 기록한다 (교재 기준).
