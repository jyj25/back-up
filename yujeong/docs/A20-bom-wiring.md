## XIAO ESP32S3 Sense 에서 이미 쓰는 핀 (Xiao.md)
- 카메라: GPIO10~18, 38, 39, 40, 47, 48
- 마이크: GPIO41(데이터), 42(클럭) / SD 카드: GPIO7, 8, 9, 21
- 비어 있는 것: D0~D5 (GPIO1~6), D6/D7 (GPIO43/44, UART TX/RX)

## 핀 계약 (제안, 서보를 XIAO 에 연결하는 경우 — ADR-03)
| 신호 | 핀 | 비고 |
| --- | --- | --- |
| 서보 PWM | D0 (GPIO1) | 카메라·SD·마이크와 겹치지 않음 |
| XIAO ↔ UNO 시리얼 | D6(TX) / D7(RX) | UNO 의 TX(5V)를 XIAO RX(3.3V)에 직접 연결하면 안 됨 → 분압 또는 레벨 변환 필요 |
| GND | 공통 | 모든 장치의 GND 를 연결 |

## 전원 (Xiao.md 기준)
- 웹캠 예제에서 평균 약 140mA, 이미지 캡처 피크 약 347mA (Type-C 5V).
- 서보는 순간 전류가 크므로 **XIAO 의 3V3 핀에서 전원을 받지 않는다.** 5V 핀(USB 전원) 또는 별도 전원을 쓰고, USB 포트 한계를 시험으로 확인한다. (3V3 핀은 700mA 까지, 서보에 쓰기엔 부적합)
- 서보가 움직일 때 보드가 재부팅되면 전원 문제로 보고 별도 전원/콘덴서를 검토한다.

## 펌웨어·통신
- 영상 전달 펌웨어: `yujeong/firmware/xiao_stream` (esp32 core 3.3.12, `PSRAM=opi`)
- 시리얼 속도: 115200 (USB CDC 는 속도 무관)
- BOOT 버튼을 누른 채 USB 를 꽂으면 부트로더 모드 (포트가 안 잡힐 때)
