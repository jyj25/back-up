# xiao_sorter — 쓰레기 판정 로직

- `sorter_logic.h`: 판정 알고리즘 (하드웨어·모델과 무관한 순수 로직). 설명은 파일 맨 위 주석 참고.
- `test_logic/`: 보드에서 직접 돌리는 시험 스케치 (시리얼 115200 에 PASS/FAIL 출력).

## 동작 요약
1. 프레임마다 클래스별 확신도를 `Sorter::update()` 에 넣는다.
2. 1등 확신도 ≥ 0.80, 1·2등 격차 ≥ 0.20, `empty` 가 아니고, 같은 결과가 3번 연속이면 **DECISION** 을 한 번 낸다.
3. 판정 뒤에는 `empty` 가 3번 연속 나올 때까지 새 판정을 내지 않는다 (같은 물건 중복 방지).
4. 10초 안에 안 비면 **STUCK** (물건이 안 떨어짐 → 알림/재시도는 호출하는 쪽이 결정).

기본값은 `Config` 에서 바꾼다. 라벨 순서가 다르면 `empty_idx` 를 맞춘다 (EI 는 알파벳순: can, empty, general_trash, paper, pet — 5클래스면 num_classes=5).
이 로직은 모델 학습 전에 만든 것이라, 실제 정확도·확신도 분포를 본 뒤 기준값을 조정해야 한다.
